# 本地辅助脚本数据契约

两个脚本只用 Python 3.9+ 标准库，无网络、无凭据操作，不修改输入。输出必须是新文件路径，以独占创建防止覆盖；父目录须已存在。结果含案件定位信息，留在获准本地目录，不放进公共Git仓库。脚本不是经过专门检测的软件，不以测试通过代替机构的方法确认。

## evidence_manifest.py

~~~sh
python3 scripts/evidence_manifest.py create --root /path/to/materials --output /path/to/new-manifest.json
python3 scripts/evidence_manifest.py verify --root /path/to/materials --manifest /path/to/new-manifest.json
~~~

应从技能目录运行，或使用脚本绝对路径。清单放在 root 目录之外，避免把清单自身当检材；root应只指向本次需登记的材料。按相对路径排序，保存字节数和SHA-256，逐文件流式读取。对符号链接、特殊文件、读取中变化及不安全相对路径拒绝处理，不跟随链接离开指定范围。核验输出新增、缺失和内容变化；不删除或自动修复。

清单不生成法定检材编号，不采集身份证明、取证手续或完整业务语义，不证明原始来源、正式交接及数据完整。目录核验是某一读取时段的比较，不是卷级一致快照；并发改动目录时应停止写入并在稳定状态重新核验。修改时间用于读取中变化检查，核验内容以路径、字节数和哈希为准。

退出码：0表示创建成功或内容核验相同；1表示核验发现差异；2表示输入、路径、权限或清单结构错误。输出文件创建失败时不会覆盖既有内容。

## audit_ledger.py

只对人工/程序已按来源语义确认的规范化CSV复算，不能直接将任意银行Excel改后缀使用。CSV采用UTF-8或UTF-8 BOM，以下列名全部存在：

| 字段 | 约定 |
| --- | --- |
| record_id | 本次数据中唯一的记录标识，不是自动认定的经济事件编号 |
| source_id | 来源文件编号，非空 |
| source_locator | 原工作表/物理行，或页/原记录位置，非空 |
| account_id | 本方账户文本标识，非空 |
| counterparty_id | 原对手账户标识；可为空，空不代表同一主体 |
| occurred_at | ISO日期时间，至少到秒，如2025-01-05T10:00:00；时区与源转换过程另行记录 |
| direction | in 或 out，表示本方原收付方向 |
| amount | 十进制文本，最多两位小数，可为负数；无千分位、指数、正号、前后空格 |
| currency | 三位大写币种代码；本脚本统一按0.01单位精度计算 |
| summary | 原摘要文本，可为空，仅保存不作真实用途判断 |

账号、日期等字段不接受隐式去空格或补全。不同币种独立分组。需要其他小数精度的数据应使用另行验证的方法，不预先舍入到本脚本格式。

本脚本假设负值为相同方向金额的抵减，例如 out -100.00 抵减出账100.00；这一语义必须先由来源规则确认。使用整数最小单位计算，输出正、负、零条数及金额、按原符号合计和净流入。原输入条数与所选条数分别报告，非交易有效性判定。

~~~sh
python3 scripts/audit_ledger.py /path/to/normalized.csv   --account SYN-CORP-A --counterparty SYN-CARD-X   --start 2025-01-01 --end 2025-01-31 --output /path/to/new-audit.json
~~~

account/counterparty可重复，按精确文本匹配；省略表示本输入中所有对应标识。日期按规范后记录的日历日期、起止日均包含；脚本不转换时区。不提供关键词筛选，防止把摘要子集冒充同账户期间全量。无命中视为需检查的输入/范围错误（退出2），不自动出具“未发生交易”的结论。

所有输入行先验证，再筛选；其他期间的坏行同样阻止成功输出。重复record_id、重复source_id+source_locator和逐行格式错误返回 errors，groups与selected_records为null，退出2，不给看似可用的部分合计。文件无法读取、表头不合格或CSV本身无法解析时，只向标准错误输出原因并退出2，不生成结果文件。该源定位约定必须精确到单条记录，不能只填一个包含多笔交易的页号。相同业务流水或镜像可能有不同记录ID，脚本不会识别或删除，须在上游明确有效/重复/异常集合后分开输入。

JSON包含规范输入文件SHA-256、明确筛选条件、选择明细及原始定位、每账户/币种的实际首末记录日期与合计。选中明细会保存在内存中，大规模任务须另行评估资源并选择适用工具，本脚本没有百万级性能验收。为避免同笔镜像相加，不给跨账户经济总额，也不验证余额、原件对应关系、主体映射、银行到账、资金归因、获利或损失。输出不具有正式鉴定意见效力。

退出码：0为本次格式及算术检查通过；2为输入/输出错误。错误结果也写入指定新文件，便于保留异常，但不得作为完成的复算结果。不得只截取成功金额而忽略退出码和errors。
