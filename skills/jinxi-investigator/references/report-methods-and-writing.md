# 资金检验方法与报告编制

按已确认的检验事项组织账户、源记录、汇总表和结论，保证每项结果都能追溯至相应数据。根据检验对象选择资金路径、账户收支或用途摘要分析，明确各方法能够支持的结论范围。

## 多级账户转付检验

先列账户及其反馈期间、总体收支规模，再按资金路径逐段检验首级收款与后续支付。每段写明付款账户、收款账户、期间、笔数、金额及对应依据，配套逐笔表或汇总表；检验结果按原要求顺序作答。

收付方向使用“甲从乙收取”或“乙向甲支付”等明确句式。各级转付属于资金流转环节，同一资金经过多个账户时不得重复累加。是否属于同一经济事件，应结合账号、流水、时间、状态和双方记录核验。

## 公司付款后个人账户检验

先检验公司向指定个人账户的付款，再检验该个人账户后续期间的收支、余额和支出摘要。按“账户总体收支—目标付款—其他来源—后续支出”组织过程，分别列明期初余额、期间收入、期间支出及期末余额。

混同其他来源资金时，不得仅因支出金额较大或期末余额较低认定指定款已全部使用。账号与卡号、主体不同名称之间的映射须有依据；摘要分类只表示记录中的用途记载，实际用途判断需要相应证据。

## 文书结构与模板

本技能的报告模板采用以下结构；单位获准模板或适用规范有明确要求时，按其执行。

1. 一、绪论：委托单位、送检人、受理日期、案件情况摘要、送检材料、鉴定要求、检验开始日期、检验地点，共八栏。
2. 二、检验：（一）检验工具、（二）检验方法、（三）检验过程。先说明账户整体范围，再按事项开展专项检验。
3. 三、检验结果：按要求顺序逐条答复，关键笔数、金额、方向和期间在本节直接写明。
4. 四、特别事项说明：材料范围、影响结论的差异及限制；随后安排附件目录、签署区和附件正文。

检材属性表和鉴定账户表置于绪论相应位置。检验过程表顺序编号，表上方标表题，金额单位单列，正文准确引用。签署区位于附件目录之后、附件正文之前；资格附件使用真实取得且获准使用的材料。

页面、字体、行距、段距和署名位置以单位模板为准。未指定模板时，可采用A4、上下边距约3.6厘米、左右约2.7厘米，主标题约22磅小标宋、正文约16磅仿宋、首行两字，一级标题黑体、检验小节楷体、表格宋体作为排版起点；这些参数不构成全国统一强制要求，应结合内容和实际阅读效果调整。

在模板工作副本中保留分节、段落/run直接格式、页眉页脚、页码字段和表格布局，清除其他任务的业务内容、身份、签章及附件。修改Normal样式不能替代对完整模板的核对。表过宽时分表或用附表；缺字体时记录替代情况，PDF预览不能证明原字体设备验收。

## 质量核查要求

| 核查项目 | 执行要求 |
| --- | --- |
| 事项响应 | 用事项矩阵确定待证明问题，直接写明查得结果；限制说明对应受影响的结论 |
| 检索范围 | 关键词结果与同账号、同期间的完整交易范围分别核对，标明子集和总量 |
| 双侧覆盖 | 按账号核对付款与收款两侧，检查其他卡号、空白户名、曾用名及各自反馈期间 |
| 主体映射 | 保留原始名称和账卡号，记录映射依据，未解决的冲突分别列示 |
| 跨系统勾稽 | 展示银行与系统记录、对应键及差额，不自动把差额解释为手续费 |
| 事件口径 | 银行实收、支付结算、系统发放及平台成交分别定义，识别同笔和包含关系 |
| 版本同步 | 新记录、期间或口径变化同步更新事项、过程、结果、附件及最终导出文档 |
| 程序事实 | 核实机构登记、受理、文号、备份方式、复核和签发状态，按实际情况填写 |

## 自然、准确的行文

正文围绕“账户、期间、方向、对象、笔数、金额、依据”展开。例如：
“在所列期间，甲账户向乙账户付款4笔，合计3,400.00元。其中，摘要含‘充值’的3笔，合计3,200.00元，其余1笔200.00元。明细见表2-2。”

用具体检验动作、记录和结果表达结论，避免“闭环赋能、穿透抓手、多维印证、强支撑”等空泛词及反复铺陈。“证明”须对应明确命题和证据，不以修辞增强确定程度。

案件背景中的涉嫌行为归属于来源文书，检验结果只陈述实际查得内容。改变结论含义的限制紧随该结论；技术细节和未影响结果的差异放入记录或特别事项。行文以清晰、准确和可复核为目标，工具使用按适用披露要求处理。
