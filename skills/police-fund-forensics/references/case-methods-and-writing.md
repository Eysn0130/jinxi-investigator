# 两份案例的方法总结与报告写法

本文件依据获准查阅的两份定稿文书及实际编制修订经验进行匿名概括。未转载原文书，不复核两案实质结论。以下版式是参考案例的实测习惯，不是全国统一强制参数。

## 案例A：多级账户转付

以几个具体账户为对象，要求分别检验首级收款和后续各级支付。绪论列账户与检材；检验先列账户总体规模，再顺资金路径逐段陈述“付款账户→收款账户、期间、笔数、金额”，每段对应统计表；结果依次回应原有要求。

可复用：路径分段、先整体后专项、每项有表、结果不增新事项。需要改进：避免“甲向乙的收款”方向歧义，改用“甲从乙收取”或“乙向甲支付”；各段是流转环节，不能把同一款项重复累加。

## 案例B：公司付款后个人账户用途

先检验公司向个人的指定付款，再延伸检验个人收款后的收支、余额和支出摘要分类。可用“账户总体收支—目标付款—其他来源—后续支出”的顺序解释个人账户活动。

可复用：期初、收入、支出、期末余额的勾稽，逐笔表与分类表配合。需要改进：混同其他资金时不能由“收款后支出很多、余额很低”断言指定款已全部花完；账号与卡号、主体不同名称必须解释映射；摘要分类不自动认定真实用途。

## 两案共同结构与母版使用

1. 一、绪论：委托单位、送检人、受理日期、案件情况摘要、送检材料、鉴定要求、检验开始日期、检验地点，共八栏。
2. 二、检验：（一）检验工具、（二）检验方法、（三）检验过程。账户总体范围后按事项开展专项。
3. 三、检验结果：按要求顺序逐条答复，关键笔数、金额、方向和期间在本节直接写明。
4. 四、特别事项说明：材料范围、影响结论的差异及限制；随后附件目录、签署区、附件正文。

检材属性表和鉴定账户表置绪论相应位置。检验过程表顺序编号，表上方为表题，金额单位单列，正文有准确交叉引用。签署区位于附件目录之后、附件正文之前；资格文件只放真实取得且获准使用的材料。

两案均为A4，上下边距约3.6厘米、左右约2.7厘米；主标题约22磅小标宋，正文约16磅仿宋、首行两字，一级标题黑体、检验小节楷体，表格多用宋体。两份行距、表题段距及署名位置有差异，不能宣称全篇统一某一数值。

有获准母版时复制母版到工作文件，保留实测的分节、段落/run直接格式、页眉页脚、页码字段和表格布局；清除原案内容、机构地址、人员、文号、签章及附件。不要只修改 Normal 样式就称保留格式。表过宽时分表或用附表，保证可读；缺字体应记录替代情况，PDF预览不能证明原字体设备验收。

## 实际报告形成经验转成的检查

| 形成过程中的问题 | 固化方法 |
| --- | --- |
| 报告只叙述案情和缺口，未回答资金证明问题 | 用事项矩阵确定问题，写明查得的具体结果；缺口只限定受影响结论 |
| 按“充值”等关键词找齐后，遗漏同卡的其他付款 | 同账号同期间再做全量检索，标明摘要子集与总量 |
| 个人侧只见部分卡，公司侧还有其他卡或空白户名 | 双侧按账号核查，分别列覆盖范围，不勉强求同 |
| 同号不同户名、不同账号近似 | 保留原字段、建立有依据的映射，冲突不抹平 |
| 银行付款与系统登记同日同额或存在小差额 | 相邻展示双方记录和差额，继续核查，不自动解释为手续费 |
| 平台成交与银行、支付、系统数据混写 | 分别定义事件与期间，明确包含及重复关系 |
| 补进新时期交易，却只改过程不改结果和附件 | 通过事项矩阵定位全部受影响文书及复核文件，同步复核 |
| 把编制日期和模板文号当成机构登记、把本地备份写成镜像 | 逐项核实实际状态，模拟编排另标，不声称正式完成 |

## 自然、准确的行文

正文以“账户、期间、方向、对象、笔数、金额、依据”为中心。例如：
“在所列期间，甲账户向乙账户付款4笔，合计3,400.00元。其中，摘要含‘充值’的3笔，合计3,200.00元，其余1笔200.00元。明细见表2-2。”

不要堆叠“闭环赋能、穿透抓手、多维印证、强支撑”等空泛词，也不要反复写“经全面深入分析”。写清具体做了什么、查到什么就足够。“证明”须有明确命题与对应证据，不以修辞增强确定程度。

案件背景中的涉嫌行为归属于来源文书，检验结果只陈述实际查得内容。限制按影响大小安排：改变某结论含义的限制紧随该结论；技术细节和未影响结果的差异放记录或特别事项。改善语言的目的是清晰可核，不承诺规避AI检测或隐藏依法应披露的工具使用。
